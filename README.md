# PowerWave4_Test

파워웨이브 4부 테스트 웹페이지

[회원가입.md](회원가입.md) 요구사항을 React + Vite로 구현한 회원 시스템 MVP입니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
```

```bash
npm run build    # dist/ 로 정적 빌드
npm run preview  # 빌드 결과 미리보기
```

## 화면 구성

| 경로 | 화면 | 설명 |
| --- | --- | --- |
| `/` | 로그인 | 첫 화면. 로그인 / 회원가입 / 아이디 찾기 / 비밀번호 찾기 버튼 |
| `/signup` | 회원가입 | 아이디, 비밀번호, 이메일, 이름, 주소, 연락처, 기타 정보 입력 |
| `/find-id` | 아이디 찾기 | 이름 + 이메일로 조회, 아이디 일부 마스킹 표시 |
| `/find-password` | 비밀번호 찾기 | 아이디 + 이메일 확인 후 임시 비밀번호 발급 |
| `/home` | 마이페이지 | 로그인 성공 후 가입 정보 확인 / 로그아웃 |

## 구조

```
src/
├── main.jsx              진입점 (BrowserRouter)
├── App.jsx               라우팅 + 로그인 상태
├── styles.css            전체 스타일
├── components/
│   ├── AuthCard.jsx      공통 카드 레이아웃
│   ├── Field.jsx         라벨 + 입력 + 에러 메시지
│   └── Banner.jsx        상단 알림 (성공/에러)
├── pages/                Login / Signup / FindId / FindPassword / Home
└── lib/
    ├── auth.js           가짜 백엔드 (localStorage)
    └── validate.js       입력 검증 규칙, 전화번호 포맷, 비밀번호 강도
```

## 입력 검증

- **아이디** — 영문·숫자·밑줄 4~20자, 중복확인 버튼 필수
- **비밀번호** — 8자 이상, 영문+숫자 포함, 강도 게이지 표시, 확인 입력 일치
- **이메일** — 형식 검사 + 중복 가입 차단
- **이름** — 2자 이상
- **연락처** — 숫자 입력 시 `010-1234-5678` 자동 하이픈
- **우편번호** — 5자리 숫자 / **주소** 필수, **상세주소** 선택
- **기타 정보** — 선택 입력

## MVP 범위 / 실제 서비스 전환 시 필요한 것

현재 데이터는 브라우저 `localStorage`에 저장되며, 비밀번호는 SHA-256으로 해싱해 두었지만
클라이언트에서 처리하므로 보안 목적이 아니라 평문 저장을 피하기 위한 것입니다.

서버를 붙일 때는 `src/lib/auth.js`의 함수 본문만 `fetch` 호출로 교체하면 됩니다.
그 외에 실제 서비스에서 추가로 필요한 항목:

- 서버 측 비밀번호 해싱(bcrypt/argon2)과 세션/JWT 발급
- 아이디·비밀번호 찾기 시 본인 확인(이메일 인증 메일, 휴대폰 인증)
- 임시 비밀번호를 화면에 노출하지 않고 메일로 발송
- 주소 입력에 우편번호 검색 API 연동
- 약관 동의 / 개인정보 처리방침 체크박스

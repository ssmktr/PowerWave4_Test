# PowerWave4_Test

파워웨이브 4부 테스트 웹페이지

[개발 기획/](개발%20기획/) 폴더의 기획서를 React + Vite로 구현한 MVP입니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:27014
```

```bash
npm run build    # dist/ 로 정적 빌드
npm run preview  # 빌드 결과 미리보기
```

### 로그인 후 — [개발 기획/메인 페이지.md](개발%20기획/메인%20페이지.md)

로그인한 계정만 접근할 수 있습니다. 세션이 없으면 `/`로 돌려보냅니다.

| 경로 | 화면 | 설명 |
| --- | --- | --- |
| `/main` | 메인 | 좌측 개인정보 박스 + 게시판 버튼, 우측 4분할 패널 |
| `/prayers` | 나의 기도 제목 | 기도 제목 추가 / 응답 체크 / 삭제 |
| `/classmates` | 반친구 | 가입한 회원 명단 (이름, 나이, 생일, 연락처) |
| `/notices` | 공지사항 | 공지 목록, 제목 클릭 시 본문 펼침 |
| `/board` | 자유게시판 | 글 목록 + 글쓰기 |

공통 레이아웃은 상단 네비바(메인 / 나의 기도 제목 / 반친구)와
하단 풋터(온누리교회 파워웨이브 4부 · 연락처 · 이메일)로 구성됩니다.

메인 우측 4분할 패널은 **공지사항, 자유게시판, 준비 중, 준비 중** 순서이며,
앞의 두 개는 최근 글 4건을 보여주고 "더보기"로 해당 게시판으로 이동합니다.

좌측 개인정보 박스는 가입할 때 받은 **이름과 생년월일**을 바탕으로
만 나이와 생일(D-day)을 계산해 표시하고, 생일 당일에는 축하 메시지가 나타납니다.

## 입력 검증

필수 항목은 **아이디, 비밀번호, 이름, 생년월일, 우편번호, 주소**입니다.

- **아이디** — 영문·숫자·밑줄 4~20자, 중복확인 버튼 필수
- **비밀번호** — 8자 이상, 영문+숫자 포함, 강도 게이지 표시, 확인 입력 일치
- **이름** — 2자 이상
- **생년월일** — 실제 존재하는 날짜, 미래 불가, 1900년 이후
- **우편번호 / 주소** — 주소 검색으로만 입력 (아래 참고)
- **연락처** *(선택)* — 입력하면 `010-1234-5678` 형식 검사, 숫자만 치면 자동 하이픈
- **이메일** *(선택)* — 입력하면 형식 검사 + 중복 가입 차단
- **상세주소 / 기타 정보** *(선택)*

> **이메일을 입력하지 않은 계정은 아이디 찾기·비밀번호 찾기를 이용할 수 없습니다.**
> 두 기능 모두 이메일로 본인을 확인하기 때문입니다. 가입 화면에도 같은 안내를 띄웁니다.
> 빈 이메일끼리 서로 매칭되는 일이 없도록 찾기 로직에서 빈 값은 걸러냅니다.

## 주소 검색

[다음(카카오) 우편번호 서비스](https://postcode.map.daum.net/guide)를 사용합니다.
API 키가 필요 없는 공개 스크립트이며, **주소 검색** 버튼을 처음 누를 때 한 번만 내려받습니다.

검색 결과로 우편번호와 도로명주소가 채워지고 상세주소 칸으로 포커스가 이동합니다.
우편번호·주소 칸은 읽기 전용이라 직접 타이핑할 수 없습니다.
네트워크 문제 등으로 스크립트를 못 불러오면 모달에 "주소 직접 입력하기" 버튼이 나타나고,
누르면 두 칸의 읽기 전용이 풀립니다.

## MVP 범위 / 실제 서비스 전환 시 필요한 것

모든 데이터는 브라우저 `localStorage`에 저장됩니다. 비밀번호는 SHA-256으로 해싱해 두었지만
클라이언트에서 처리하므로 보안 목적이 아니라 평문 저장을 피하기 위한 것입니다.

서버를 붙일 때는 `src/lib/auth.js`의 함수 본문만 `fetch` 호출로 교체하면 됩니다.
그 외에 실제 서비스에서 추가로 필요한 항목:

- 서버 측 비밀번호 해싱(bcrypt/argon2)과 세션/JWT 발급
- 아이디·비밀번호 찾기 시 본인 확인(이메일 인증 메일, 휴대폰 인증)
- 임시 비밀번호를 화면에 노출하지 않고 메일로 발송
- 게시판 글 수정·삭제, 댓글, 페이지네이션, 작성자 권한 확인
- 반친구 명단 공개 범위 설정 (현재는 연락처 가운데 자리만 마스킹)
- 약관 동의 / 개인정보 처리방침 체크박스
